# Screenshot Checklist (Windows)

Capture genuine screenshots after running the application. Suggested output folder: `docs/screenshots/`.

1. Login page (`01-login.png`): open `http://localhost:5173/login`.
2. Registration page (`02-register.png`): open `http://localhost:5173/register`.
3. Dashboard (`03-dashboard.png`): sign in and capture totals/recent records.
4. Student list (`04-student-list.png`): show table, search, status filter, and pagination.
5. Create form (`05-create-student.png`): click **Add student**.
6. Edit form (`06-edit-student.png`): open an existing record and edit it.
7. Successful CRUD (`07-crud-result.png`): capture created/updated notification and final list.
8. API docs (`08-swagger.png`): open `http://localhost:5000/api-docs`.
9. MongoDB Compass (`09-compass-records.png`): connect to `mongodb://127.0.0.1:27017`, open `student_management`, and show `users`/`students` collections. Hide sensitive details if any.
10. UML diagrams (`10-uml.png`): render diagram sources and capture a readable diagram.

**Windows screenshot options:** press `Win + Shift + S`, select the region, then save the snip as PNG. For a full-window screenshot, use `Alt + PrtScn` and paste into Paint, then save as PNG. Do not create screenshots by editing static mockups; capture the actual running app.
